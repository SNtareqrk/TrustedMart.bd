Trusted Mart .bd — Free Website
================================

Files:
- index.html: Complete responsive website in Bengali.

Free hosting using GitHub Pages:
1. Sign in to GitHub.
2. Create a new public repository named trustedmartbd83 (or another name).
3. Upload index.html to the repository's root folder.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a few minutes for the website URL to appear in Settings → Pages.

Notes:
- Product images are loaded from Unsplash, so internet access is needed to display them.
- Images are representative sample photos. Replace them with your actual product photos when available.
- No product prices are invented; customers are directed to Facebook/phone for current price and stock.
- This is a static website; it does not include online payment, a cart, or an order database.
